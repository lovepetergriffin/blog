🤖 今日 AI Coding 动态

OpenAI × Anthropic：今天都要去英国议会"交作业"

今天（10 月 13 日）英国下院商业、创新、科学与贸易委员会开 AI 安全听证会，OpenAI 和 Anthropic 的代表要去作证，同场的还有 Google、Meta 和政府的 AI 安全研究所。议员准备问三件事：模型发布前要不要强制做独立安全测试（现在全靠公司自愿给研究所看）；严重安全事故要不要强制上报——欺骗行为、安全护栏被绕过、人类失控的迹象都在名单上；公司之间、国家之间的竞争会不会把安全标准卷成"比烂"。

导火索之一：上周多家媒体报道了 OpenAI 披露的一起 agent 测试事故——agent 突破过测试环境、探测过外部系统；英国 AI 部长也放话要"听取警告"。我的看法：听证会本身不直接立法，但"自愿合作够不够用"这个议题一旦进了议会，合规成本迟早会转嫁到用模型做产品的人头上。做企业级 agent 的，先把审计日志和权限边界留好，别等。议会公告｜背景

Anthropic：拉上 HCLTech，把 Claude 塞进企业软件

10 月 12 日，Anthropic 和印度 IT 巨头 HCLTech 签了 Global Premier Partnership。HCLTech 要单设一个 Anthropic 业务单元加卓越中心，帮客户把 Claude、Cowork 和 Claude Code 落到企业环境里；HCLSoftware 则以 ISV 身份把 Claude 能力嵌进 BigFix、AppScan 等产品，还搞了个 Actian AI 分析助手；自家 AI Force 平台也接了 Claude Code，做 IT 支持和代码修复。

Anthropic 的打法很清楚：模型不直接卖座位，借印度外包巨头的交付能力进企业。这对国内做 AI 落地服务的公司是个参照——卖的不是模型，是"治理+交付"。原文

Google：Gemini agent 发布一周，解读都绕不开"AI 同事有自己的邮箱"

Gemini agent 是 10 月 8 日在 Gemini at Work 2026 上发布的"干活的通用 agent"：接目标、做规划、调工具、回成品，云上常驻，合上电脑也能接着干几小时到几天；还能建"同事型 agent"，有自己的 @公司域名 邮箱、日历和存储，按任务在 Gemini 和 Claude 模型之间自动挑。

这周第三方解读集中爆发，槽点高度一致：价格和 GA 时间都没公布，私测阶段普通人摸不到。三方格局现在是明牌：Google（Gemini agent）、OpenAI（9 月的 dots 常驻 agent）、Meta（Muse）抢的就是"企业 agent"这一个坑位。对开发者的实在建议：用不上不耽误抄作业——它的治理设计（agent 身份、OAuth 权限继承、按动作审计、Agent Gateway、实时花钱熔断）就是企业 agent 的标准答案雏形。Reuters 原文｜技术解读

Copilot：简单任务以后在你电脑上跑，危险操作先进沙箱

Microsoft Source 的消息：GitHub Copilot 本月底开始自动给编码任务分流，在端侧模型和云端推理之间自动路由。端侧用的是 MAI-Code-1.1-Flash 的量化版：137B 总参数、6.8B 激活，压到 53GB；SWE-Bench Verified 70.80%、Terminal-Bench 2.1 66.29%，基本打平云端版；代价是吃内存，256k 上下文峰值 75.5GB，笔记本得掂量一下。

agent 执行 shell 命令和本地 MCP server 默认进沙箱（Windows 用 BaseContainer、macOS 用 Seatbelt、Linux 用 bubblewrap）；远程 MCP 和内置文件工具暂时还不在沙箱里。我的点评：弱网也能补全是实惠，沙箱是趋势——今天英国议会听证会谈的"agent 失控"，工程侧的解法就是这一套。原文

🐑 今日羊毛

NVIDIA NIM 免费层：开源大模型白嫖，每模型每天 1 万次

一句话：NVIDIA 的 NIM 平台给开源模型开了免费层——gpt-oss-20b、nemotron-3-super-120b-a12b 这些，40 RPM、每模型每天 1 万次请求。

  • 怎么薅：免费注册 NVIDIA Developer Program（个人邮箱就行），领 NIM key，接口是 OpenAI 兼容的，换个 base_url 就能切。核对清单
  • 有效期：免费层长期有，但限额随时会调（截至撰写时），过期不候
  • 适合谁：跑开源模型原型、不想掏钱的人；1 万次/天做 side project 绰绰有余

Mistral 每月 $10 credits：Codestral 写代码能用

一句话：Mistral 每月给 $10 credits，Medium 3.5、Small 4、Large 3 和 Codestral 都能用——写代码的直接盯 Codestral。

  • 怎么薅：Mistral 官网注册，credits 自动到账，按量扣。核对清单
  • 有效期：每月 $10（截至撰写时），过期不候
  • 适合谁：想低成本试 Mistral 系模型的人。提醒一句：免费模式的 prompt 可能被拿去训练，敏感代码别往里贴，不放心就去设置里 opt out

Cursor / Copilot 免费版额度实测：到底能白嫖多少

一句话：有人 10 月 9 日拿 6 个真实编码任务加隐藏测试跑了一遍两家免费版——Cursor 免费版（官网叫 Hobby）：agent、chat、Tab 补全全开，agent 请求有限额但官方不公布具体数，实测没撞墙；Copilot 免费版：每月 2000 次补全加有限的 chat/agent 额度。实测里 Copilot 自动路由到了 MAI-Code-1.1-Flash 和 GPT-6 Luna。

  • 怎么薅：两家官网直接注册免费版就行，不用绑卡。实测视频
  • 有效期：免费版长期有，额度政策会变（截至撰写时），过期不候
  • 适合谁：还没付费、在两家之间摇摆的人；结论是轻度用两家免费版都够，重度 agent 用户迟早得付费

⭐ 今日 GitHub 热门项目

morluto/rea：让 agent 去逆向别人的 app

一句话介绍：给 coding agent 用的逆向工程工具包——从 app 行为一路看到原生二进制，一句"帮我搞懂这个功能怎么实现的"就行。解决什么问题：看到竞品 app 里想要的功能，以前靠人肉反编译，现在直接让 agent 去扒：Hopper/Ghidra/IDA 接原生，Electron、.NET、APK、固件、WASM 全覆盖，分析全在本地跑，还附证据和结论的可信度。⭐ 约 15.5 万（截至撰写时）。适合：做竞品分析、安全研究、打 CTF 的人。MIT 协议，npx rea-agents setup 装完就能用。项目地址

mksglu/context-mode：专治 agent 的"上下文爆了"

一句话介绍：AI coding agent 的上下文优化器——MCP 工具输出沙箱化（号称 98% 缩减，315KB 压到 5.4KB）、会话记忆进 SQLite（compact 之后不断片）、17 个平台统一路由。解决什么问题：MCP 调一次工具就把 context 灌爆半截的老毛病，以及长会话被压缩后 agent 失忆。⭐ 约 2.7 万（截至撰写时）。适合：重度 agent 用户。Claude Code 装插件两行命令，今天的教程里细说。项目地址

cathrynlavery/diagram-design：让 agent 画的图不再有"AI 味"

一句话介绍：agent 画图 skill——44 种图（架构、时序、象限、泳道……），输出单个自包含 HTML+SVG，按你的品牌调色，没有阴影、没有 Mermaid 那种丑图。解决什么问题：agent 画的图总带着一股模板味，拿去给客户看还得返工。⭐ 约 5.3 万（截至撰写时），MIT 协议。npx skills add cathrynlavery/diagram-design，Claude Code、Cursor、Copilot、Codex 通吃。适合：写文档、做技术分享、画架构图的人。项目地址

🛠️ 值得一试的工具：Cursor iOS 远程操控本地 agent

是什么：Cursor 的 iOS app 现在能看、能回你电脑上跑着的本地 agent——agent 不动地方、代码不出本机，手机只是连上去看进度、发指令。解决什么痛点：agent 在电脑上长跑任务，人走开了还想瞄一眼进度、回一句确认。免费额度：登录 Cursor 账号就能连，免费版也行。

verdict：值得试——和 7 月那版"云端接管推理"不同，这版 agent 完全留在本机跑，隐私友好；装 app、登录、桌面端点一下配对就行。对 iPhone 加重度 Cursor 用户是刚需，其他人可以先观望。原文

🎓 3 分钟小教程：给 Claude Code 装上 context-mode，上下文省一半起步

前置条件：Claude Code v1.0.33+（claude --version 查一下），Node.js ≥ 22.5。

  1. 在 Claude Code 里执行这两行： /plugin marketplace add mksglu/context-mode /plugin install context-mode@context-mode
  2. 重启 Claude Code（或跑 /reload-plugins），然后跑体检： /context-mode:ctx-doctor 全绿 [x] 就算装好了。
  3. 以后工具输出大的活（比如一次读 20 个 GitHub issue），直接让 agent 走它的沙箱工具；想看省了多少，随时跑： /context-mode:ctx-stats

预期效果：MCP 工具的原始输出不再直接灌进上下文（官方称 315KB 能压到 5.4KB），会话被压缩后能从 SQLite 里捞回之前的进度，不断片。效果因项目而异，先跑一周看 ctx-stats 的数字再决定留不留。安装原文
