美国政府下令：DeepSeek 从联邦系统里彻底清除，连你套壳的产品一起

美国国土安全部 10 月 19 日在 Federal Register 公开 Exclusion and Removal Order #2026-01（签发于 7 月 24 日，19 日公开）：要求所有联邦文职执行机构停止采购 DeepSeek 及附属机构产品，并从 IT 系统中移除现有部署——连基于 DeepSeek 实现的第三方产品/服务也一并覆盖，理由是可能向中国转移敏感数据、模型本身可能含恶意软件。60 天豁免申请窗口在公开前已经过期。

跟你有啥关系：如果你做的产品或公司供应链里嵌入了 DeepSeek（API 转售、自建网关代理、SDK 集成），美国政府采购线现在是高风险依赖；即使不在政府市场，这轮动作也预告了合规审查会继续往下游应用层延伸，第三方集成是主要打击对象。Engadget 报道

Meta 商业条款里悄悄加了"抓你的网站内容训 AI"，被发现后连夜删掉

Meta 近期更新的商业条款中写明：可用爬虫、抓取工具"访问、索引、抓取与你产品服务相关联的域名、网页、URL"，并将内容用于"提供、开发、改进、研究、训练"Meta 产品。法律专家指出，这等同于授权 Meta 抓取任何有 Meta 商业账号的出版商网站来训练模型。舆论发酵后 Meta 删除了相关措辞，澄清条款仅适用于广告和商业产品、不改变爬虫行为；修订后条款计划 10 月 30 日生效。

跟你有啥关系：如果你运营网站/博客且有 Meta 商业账号（投放广告、接 Pixel），你的网站内容在合同层面曾经被开了训练口子。现在措辞已删，但 10 月 30 日新版生效前建议审一次条款；更直接的做法是检查并收紧 robots.txt / 反爬策略，别把训练数据免费送出去。TechCrunch 报道

Anthropic 把 5% 的股权装进"公共福利基金"

Anthropic 10 月 18 日宣布设立 Anthropic Public Benefit Fund——一个由公司全资持有的 LLC，初期注入公司 5% 的股权（需股东批准），之后公司估值每超过一个未公开基准线增长 50%，董事会可酌情再追加 2%。该基金承诺不把股权用于游说或政治捐款，用途可能是给传统非营利机构的大额捐赠，或直接向特定人群发放资金（如应对 AI 造成的就业冲击）。

跟你有啥关系：对写代码的是间接信息——加上创始人 80% 股权捐赠承诺和员工股权捐赠匹配计划后，约 20% 的 Anthropic 股权被划归"公共福利"。这是在 IPO 前（传闻最早 11 月）向监管和公众做的治理姿态；Claude 的定价、API 政策短期不受影响，不必因此做技术决策。Anthropic 官方博客

Google Notebook 出"先审稿再生成"：Slide 和视频可以先看大纲

Google 10 月 19 日官方博客宣布：Gemini Notebook 的 Slide Deck 和 Video Overview 新增 co-creation 工作流——先基于你的资料建议内容主题，你确认并调整视觉风格后，还可以用新的 Review 开关在渲染前逐条检查/修改大纲笔记（slides）或制作人笔记（video）。

跟你有啥关系：直接能用——这项功能正在未来一周内向全球所有 Gemini Notebook 用户推送。常用 Notebook 做技术方案汇报、视频解读的读者，等于多了一个"先审大纲再渲染"的中间步骤，返工成本直接降；赶时间也可以跳过 Review 一步按老方式直接生成。Google 官方博客

⭐ 今日 GitHub 热门项目

MadsLorentzen/ai-job-search：把找工作做成 agent 流水线

一句话介绍：在你自己机器上跑的 AI 求职框架，基于 Claude Code：/scrape 搜岗、/apply 评估匹配度并定制 CV+求职信、/interview 模拟面试。解决什么问题：把"找工作"这套体力活做成 agent 流水线，作者本人用它投了 69 份、拿到 20 个一面，2026 年 6 月成功入职 AI 工程师。⭐ 约 56,994（截至撰写时）。适合：正在找工作的开发者；也是个学"agent 怎么做事"的现成例子。项目地址

headroomlabs-ai/headroom：LLM 之前的压缩层，token 账单砍两成

一句话介绍：工具输出、日志、文件、RAG 切片进 LLM 之前先过一层压缩。解决什么问题：agent 的 token 账单——官方 benchmark 显示 coding agent 场景省约 20% token，JSON 类载荷省 60–95%，答案不变；纯本地压缩，数据不出机器。提供库（compress(messages)）、drop-in proxy、MCP server、headroom wrap claude 一键接入。⭐ 约 76,198（截至撰写时）。适合：天天跑 coding agent、被 token 账单刺痛的人。项目地址

🛠️ 值得一试的工具：Laminar

是什么：YC S24 的 agent 可观测性平台，今天 Launch HN 带来自研 RL 模型 flow-1：把 trace 当 repo、用 agent 方式 grep 式排查，输出结构化 JSON 事件，每条 trace 自动过一遍 Failure Detector，专门找 agent 的"静默失败"（错了但没报错：错误动作、违反指令、重复失败、幻觉式保证），自称检测质量打平 GPT-6-sol、成本约 1/20；另有"从任意步骤重跑 agent"的调试器（mock 掉之前的 LLM 调用、恢复状态，不用从头再来）。解决什么痛点：agent 跑 40 分钟挂在某一步，传统 trace 是几千个 span 的"祝你好运"。免费额度：Laminar Cloud 新项目自带 Failure Detector。

verdict：值得试——agent 静默失败排查是真实高频痛点，"自然语言写规则、全量 trace 自动审计"的形态是我觉得 observability 该走的方向；但目前只适合真正在跑 production agent 的人，纯写代码的可以先收藏。Laminar 博客 / YC 页面

🎓 3 分钟小教程：给 Claude Code 接上 headroom，token 账单砍两成

前置条件：装了 Python（3.13 更顺）或 uv；正在用 Claude Code / Codex / Cursor 其中之一

  1. 装 CLI（PyPI 包才带 headroom 命令，npm 包只有 SDK）： bash pip install "headroom-ai[all]" 或 uv tool install --python 3.13 "headroom-ai[all]"
  2. 一键接入你的 agent（codex / cursor / copilot 等换名字就行）： bash headroom wrap claude 反悔了用 headroom unwrap claude 撤销，干净。
  3. 先体检再看账单： bash headroom doctor # 健康检查，确认路由生效 headroom savings # 实时看省了多少 token

预期效果：之后每次 agent 会话的工具输出/日志先在本地压缩再发给模型，答案不变；官方 benchmark 里 coding agent 场景省约 20%，你自己的数以 headroom savings 为准。我觉得这是目前性价比最高的"省 token"姿势：不改代码、不换模型，纯赚。headroom 项目
