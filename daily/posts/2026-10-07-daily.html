🤖 今日 AI Coding 动态

Google 发布 Gemini 4 Argon：首款 Gemini 4，DeepSWE 77.9% 刷新纪录

9 月 30 日 Google DeepMind 发布的 frontier 新模型，主打三块：长程真实软件工程、企业知识工作、网络安全防御。成绩单挺硬：DeepSWE v1.1 77.9%（超了 GPT-6 Astra 的 74.1% 和 Claude Opus 5.5 的 74.2%），AutomationBench 51.3%，最抓眼球的是输出上限从 64K 一口气提到 100 万 token——一个 trajectory 能写几十万字不带断的。API 促销价 $2/$10 per MTok（缓存输入 95% off），促销期后翻倍。

但别急着换模型：分阶段上线，先给 Fairwind Program 的可信网络安全研究员和美国政府早期接入，公共 API 还没影，连模型 ID 都没有。Bloomberg 还曝出内部有人质疑"benchmark 强、实际干活一般"，Google 否认了。速览卡片 / 完整 benchmark 表与定价 / 发布细节（链接截至撰写时可访问）

我的看法：这轮是"长程 agent 任务"的军备赛，1M 输出是结构性变化——意味着以后整个仓库级迁移可以一次跑完。国内用不了，先看热闹，等 API 开了再说。

Google Antigravity：Claude 5.5 上车，但只给付费档，11 月 2 日免费版断第三方模型

10 月 3 日 Antigravity 的模型文档更新了：Claude Sonnet 5.5 (thinking)、Claude Opus 5.5 (thinking) 进了模型选择器，但仅限 Google AI Pro（非试用订阅）和 Ultra。免费版、Plus、试用期 Pro、企业版全部无缘。同页还写明：Claude 4.6 系列和 GPT-OSS-120B 将在 11 月 2 日移除——免费档现有的 Claude 访问通道彻底关闭。文档核验 / 影响分析 / 各档位对照（链接截至撰写时可访问）

说白了：第三方模型每 token 都是真金白银付给 Anthropic 的 API 账单，免费薅 Claude 的日子进入倒计时。现在还在免费档用 Claude 跑 agent 的，这一个月赶紧把工作流迁到 Gemini 或别的模型上，别等 11 月 2 日当天抓瞎。

GitHub Copilot Code Review：出了 API，默认档从 Lite 切到 Balanced，账单变贵了

10 月 2 日的 changelog 里藏了个账单相关的大变化：Copilot code review 出了 REST/GraphQL API，可以按次指定 effort 级别；同时 9 月 28 日起默认级别已从 Lite 切到 Balanced。Balanced 会用更强的推理模型深审复杂逻辑，代价是更多 AI credits，还要吃 GitHub Actions 分钟数。关键是：如果仓库配了"每个新 PR 自动请求 review"，这笔消耗记在 PR 作者头上，不是组织统一账单——开 PR 最勤的人涨幅最大。变化解析（链接截至撰写时可访问）

建议：管理员这周检查一下四层覆盖设置（企业 → 组织 → 仓库 → 个人），走 API 调 review 的 CI 任务记得显式传 Lite，不然默认就是贵的那个。

⭐ 今日 GitHub 热门项目

mattpocock/skills

Total TypeScript 作者 Matt Pocock 的实战 agent skills 合集，直击 agent 四大翻车现场：需求对不齐（/grill-me 先拷问你一轮）、话太多、代码跑不起来（/tdd 红绿重构）、agent 加速造屎山（/improve-codebase-architecture 定期体检）。解决什么问题：vibe coding 一时爽，工程纪律全靠 skills 补回来。⭐ 约 278,095（截至撰写时）。适合：每天被 agent 气到的程序员，Claude Code 官方市场一键装，Codex 也支持。项目地址

pbakaus/impeccable

让 AI 画出不像 AI 的前端设计的 skill：1 个 skill + 24 条命令（polish/audit/critique/animate/bolder…），60 条确定性检测规则专治 AI 设计味——Inter 字体、紫蓝渐变、卡片套卡片、灰字压彩底，一个不留。npx impeccable install 一条命令装进 Claude Code / Cursor / Codex。解决什么问题：agent 写的页面一眼 AI 味，改都不知道从哪下手。⭐ 约 77,666（截至撰写时）。适合：经常让 agent 写落地页、管理后台的人。项目地址

ayghri/i-have-adhd

让 coding agent 停止废话的 skill：先给行动、步骤编号、不说"Hope this helps!"，10 条铁律（无废话开头、无总结、无客套收尾、列表不超 5 项）。解决什么问题：agent 回复三页纸，答案藏在第三段——这个 skill 把输出压成 ADHD 友好格式，扫一眼就能干活。⭐ 约 54,383（截至撰写时）。适合：看 agent 长篇大论就烦、只想看下一步干啥的人。项目地址

cathrynlavery/diagram-design

让 agent 画编辑级架构图的 skill：42 种图类型（架构、时序、ER、桑基、Wardley 地图……），自包含 HTML+SVG 输出，口号是"No Mermaid slop"，还能读你的网站 60 秒匹配品牌风。解决什么问题：让 Claude 画架构图，次次都是圆角方框灾难；这个直接出能放进文档和分享里的成品图。⭐ 约 43,997（截至撰写时）。适合：写技术文档、做分享、画系统架构图的人。项目地址

morluto/rea

给 agent 的逆向工程超能力：一个 MCP 接入 Ghidra / Hopper / IDA，从应用行为到原生二进制都能查。"看到别人家 App 的功能想抄？让 agent 逆向一下，它会给你证据和结论。"分析全在本地跑，还附带每条结论的证据和局限说明。解决什么问题：agent 会写代码但不会"看"没有源码的软件。⭐ 约 9,259（截至撰写时）。适合：安全研究、竞品分析、CTF 玩家。提醒：逆向仅用于学习和授权场景。项目地址

🛠️ 值得一试的工具：Together Link

是什么：Together AI 10 月 5 日发布的免费 CLI（MIT 开源，beta 中），把你已经在用的 coding agent——Claude Code、Codex、OpenCode、Pi、Claude / ChatGPT 桌面版——接到 Together 托管的开源模型上。Kimi K3、GLM 5.3 主攻硬核 coding，GLM 5.3 Flash、DeepSeek V4.1 Flash 覆盖日常任务，Auto 路由按会话自动选模型。

解决什么痛点：agent 把所有任务都往同一个旗舰模型上怼，一行小 fix 也烧最贵的 token。Together Link 是"换壳不换操作习惯"：装完 togetherlink claude 一把梭，官方称账单能省 50%+，配置可逆（togetherlink chatgpt off 切回去）。

免费额度：CLI 本身免费开源；需要一个 Together API key（Together 有免费额度/按量计费，开源模型本来就便宜）。

verdict：值得试 —— 试错成本几乎为零，配置可逆不锁死；但 beta 期命令和模型列表可能变，先拿非关键项目试，别直接上生产流程。发布介绍（链接截至撰写时可访问）

🎓 3 分钟小教程：给 Claude Code 装上 Matt Pocock 的实战 skills，让 agent 先对齐再开工

Trending 第一那个 skills 仓库，我装完试了下，最值的其实是工作流纪律。下面是 3 分钟装好。

前置条件：Claude Code 已安装并登录（claude --version 能跑就行）

  1. 装插件（二选一，装一个就行）： claude plugins install mattpocock-skills 或在会话里跑 /plugin install mattpocock-skills。用 Codex / 其他 agent 的话： npx skills@latest add mattpocock/skills
  2. 每个仓库跑一次初始化（选 issue tracker、triage 标签、文档放哪）： /setup-matt-pocock-skills
  3. 下次开需求别急着让 agent 写代码，先跑 /grill-me：它会像老练的 tech lead 一样先拷问你一轮需求细节，对齐了再开工。修 bug 用 /diagnosing-bugs（分阶段诊断循环），写功能用 /tdd（红绿重构）。

预期效果：agent 不再自说自话开干——需求先对齐、测试先写、bug 按流程诊。装的是可编辑的 skill 文件，哪条不顺手直接改成自己的。项目地址
