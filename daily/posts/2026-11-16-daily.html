Anthropic：Opus 5.5 的提示词该换写法了——删掉"think hard"，从 Medium 档起步

跟你有啥关系：你的 claude.md 与系统提示里还留着老习惯的话，正在白白烧 token。

Anthropic 11 月 14 日经 The Decoder 披露的 Opus 5.5 使用指南称：Opus 5.5 默认开启思考、按任务自动调推理深度，提示词里的"think hard""think carefully"这类话可以删了——内测显示去掉后回答启动更快、质量没有可测的下降。档位建议也反过来了：从默认的 Medium 起步，Opus 5.5 在 Medium 下的内测表现与 Opus 5 的 High 相当；Sonnet 5.5 拉到超高档位的成本已接近 Opus，不如直接换模型。写法上：一句话给目标、一次说完、把文件直接贴给模型，别分段喂指令，也别写自相矛盾的规则——新模型会认真执行每一条，撞上了反而糊涂。Claude Code 2.1.319 起内置了提示词审计（/doctor prompt-audit），今天的教程就是拿它跑一遍。原文链接

🎓 3 分钟小教程：给 Claude Code 跑一次提示词审计

前置条件：Claude Code 2.1.319 或更新版（claude --version 确认）。

  1. 在 Claude Code 里输入 /doctor prompt-audit（别名 /checkup）：它会逐行审你的 claude.md 与配置，按 keep/remove/rewrite/move 四类给修改建议
  2. 重点删这几类：think step by step、double-check your work、be maximally thorough 这类脚手架，以及自相矛盾的规则——新模型自己会思考、会自查，这些词只烧 token，有时还降准确率
  3. 调 API 的代码库用 /claude-api prompt-audit 同样审一遍；审完把 effort 从 High 降回 Medium（Opus 5.5 默认），只在 Medium 搞不定时再往上加

预期效果：一次审计 10 分钟左右；旧提示词清掉后，Opus 5.5 在 Medium 下的表现与旧版 High 相当，token 账单先降一截。出自 Anthropic 工程师 Lance Martin 的分享与 Claude Code 内置审计（原文）。
