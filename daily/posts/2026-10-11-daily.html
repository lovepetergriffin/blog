morluto/rea：让 agent 逆向任何软件

🎓 3 分钟小教程：给 GitHub Copilot CLI 装上 context-mode

前置条件：Node.js ≥ 22.5，GitHub Copilot CLI（copilot 命令）已安装并登录。

  1. 全局安装 context-mode（MCP server 跑的是这个二进制）： bash npm install -g context-mode
  2. 一条命令装插件（自动注册 MCP server + 路由 skill + 抓取 hooks）： bash copilot plugin install mksglu/context-mode:configs/copilot-cli
  3. 打开 Copilot Chat 输入 ctx stats 验证：能看到 ctx_* 工具列表即成功。

预期效果：之后 agent 的工具输出走沙箱而不是全量塞进上下文，官方称能减少约 98% 的工具输出 token；会话记忆跨会话保留，compact 也不丢。
