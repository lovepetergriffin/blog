🤖 今日 AI Coding 动态

OpenAI Day 5：Dots 上手机 + Codex composer predictions beta（Pro）

10 月 9 日，OpenAI"28 天品质提升"计划进入第 5 天。Dots：首次支持直接在 iOS/Android 版 ChatGPT 手机 App 上创建；dot 现在可以在 Codex 里启动工作、跟进已有 thread，还能查看/编辑 ChatGPT Work 的 Scheduled Tasks。官方论坛帖

Codex composer predictions（beta）：为 ChatGPT Pro 用户推出"下一条消息建议"，按 Tab 接受；beta 期间不耗额度。官方论坛帖（链接截至撰写时可访问）

我的看法：Dots 正在从"好玩的个人助手"变成"任务委派入口"——手机上随手建一个 dot，回家打开 Codex 接着干，异步工作的闭环感有了。composer predictions 这类"下一条建议"反而是高频场景里体感最强的改进，能省掉不少打字。

Google：Gemini App 免费版从 10 月 9 日起只剩 Flash-Lite

按 Google 官方支持页"Changes to Gemini model access and limits"的口径：自 10 月 9 日起，无 Google AI 订阅的用户在 Gemini App 中只能使用 Flash-Lite，Flash 与 Pro 被移除；AI Plus（$4.99/月）保留 Flash-Lite 和 Flash，但失去 Pro；AI Pro（$19.99/月）保留全部三档并新增 Deep Think（此前仅 Ultra 有）。pondero 整理（截至撰写时可访问）

我的看法：这是 Google 顺着前几天 Antigravity"免费版 11 月 2 日断第三方模型"的思路继续收紧免费档。免费用户能用的模型一再下移，用脚投票的人会变多——但对 Google 来说，免费转付费就是它要的效果。写代码的重度用户，建议早点做付费或换渠道的打算。

Anthropic：官网这两天无新发布，Usage Policy 更新继续发酵

Anthropic 官网 Newsroom 在 10 月 9–10 日没有新发布。仍在发酵的是 10 月 8 日官宣的 2026 Usage Policy 更新：新增禁止对 Claude"sustained and needless abusive or cruel behavior"（持续且无意义的辱骂/残忍行为）条款，11 月 12 日生效；Claude 终止对话仍是主要执行手段；同时收紧选举欺骗、虚假宣传、武器软件、监控相关规则。TechCrunch 报道（截至撰写时可访问）

我的看法：这条之前报道时我当它是产品新闻，回头看它真正的分量是合规信号——各家都在给模型行为立规矩。以后企业采购 AI 时，"usage policy 长什么样"会变成选型材料的一部分。

Xcode 26.3 RC：agentic coding 内置，可选 Claude Agent / Codex / MCP 自定义 agent

Xcode 26.3 RC 内置 agentic coding，可选 Claude Agent、OpenAI Codex 或经 MCP 接入自定义 agent；可直接在 Xcode 内读写工程、构建、跑测试。iOS 开发者不用插件就能调用 Claude Code 级能力。DEV 社区文章（截至撰写时可访问）

我的看法：苹果终于把 AI coding 搬进官方 IDE 了——之前 Xcode 的 AI 补全一直被诟病，这次直接接入第三方 agent 倒是个务实的选择。对 iOS 开发者来说，最大的变化是"不用再装一堆插件"，工程内直接调 agent 跑测试修 bug。不过是 RC 版，等正式版再上生产项目。

⭐ 今日 GitHub 热门项目

alibaba/open-code-review

阿里内部 AI 代码评审助手的开源 CLI 版（命令 ocr）。解决什么问题：通用 agent 做 code review 时漏文件、定位漂移、质量不稳定——它用"确定性 pipeline + LLM Agent"混合架构（文件分组、规则匹配、行级定位），官方 benchmark 称同模型下精度和 F1 显著高于 Claude Code，且只耗约 1/9 token。⭐ 约 45,178（截至撰写时）。适合：想把 AI code review 接进 CI、又怕 agent 乱评的人。项目地址

BerriAI/litellm

统一 LLM API 网关（Rust 核心 + Python SDK）。解决什么问题：多厂商模型 SDK/Auth/格式各异——它提供 OpenAI 格式的统一调用，内置费用追踪、guardrails、负载均衡、日志；覆盖 100+ 厂商（OpenAI/Anthropic/Gemini/Bedrock/Azure/Vertex/vLLM 等），也支持 MCP 与 A2A agent 网关。⭐ 约 60,645（截至撰写时）。适合：项目里要切多个模型、想做统一计费和网关的人。项目地址

ifixai-ai/iFixAi

AI agent 独立审计工具，120 秒出诊断报告。解决什么问题：现有评测只看技术指标，回答不了"agent 是否按业务 KPI 在做事"——它做对抗式红队 + 运营保障审计，输出可引用的打分卡；以 Claude Code / Codex 插件、slash skill、CLI 三种形态运行，支持多厂商交叉评审。⭐ 约 23,012（截至撰写时）。适合：要把 agent 放进生产流程、先做一轮独立审计的团队。项目地址

TencentCloud/Octop

腾讯云开源的自托管多用户多 agent AI 助手平台。解决什么问题：个人/家庭/小团队想把对话、记忆、凭证全留在自己机器上，又要多 agent 并行、IM 渠道（飞书/钉钉/QQ/微信/Telegram/Discord）接入和定时任务——一条命令起 Web 控制台 + CLI + cron，还可通过 ACP 把编码任务委派给 OpenCode/Claude Code/Codex。⭐ 约 8,235（截至撰写时，MIT，有中文 README）。适合：想自己搭"家庭 AI 中枢"、数据不想上云的人。项目地址

twostraws/SwiftUI-Agent-Skill

Hacking with Swift 作者 Paul Hudson 做的 SwiftUI agent skill。解决什么问题：LLM 写 SwiftUI 时常犯 VoiceOver 不可见、用弃用 API、性能坑等错——这个 skill 把几千小时实战经验做成检查规则，一句话装进 Claude Code / Codex / Gemini / Cursor 等 agent（npx skills add 或 /plugin install）。⭐ 约 5,411（截至撰写时，MIT）。适合：用 agent 写 SwiftUI 的 iOS 开发者。项目地址

🛠️ 值得一试的工具：TencentCloud/Octop

是什么：腾讯云开源的自托管多用户多 agent AI 助手平台（上面项目栏也介绍过）。

解决什么痛点：个人/家庭/小团队的 AI 助手需求——对话、记忆、凭证想全留在自己机器上，同时又要多 agent 并行、IM 渠道接入、定时任务。它是"一条命令起 Web 控制台 + CLI + cron"的 all-in-one，数据全在 ~/.octop/。

免费额度：开源 MIT，完全免费，自己机器跑就行；模型用自己的 API key（支持 OpenAI 兼容 API、DashScope、Ollama 等）。

verdict：值得试 —— 8k star、腾讯云官方背书、中文 README，对国内用户最友好的自托管 agent 平台。不过注意它是个"平台"不是"开箱即用助手"，动手能力弱的会觉得配置多；但对折腾党来说，一台 NAS/小主机就能跑全家人的 AI 中枢，值回票价。项目地址（链接截至撰写时可访问）

🎓 3 分钟小教程：3 分钟把腾讯云开源的 Octop 跑起来

上面刚介绍的 Octop，腾讯云的自托管多 agent 助手。今天不讲概念，直接跑起来。

前置条件：macOS 或 Linux 机器；一个模型提供商的 API key（OpenAI 兼容 API、DashScope、Ollama 都行）

  1. 一键安装（官方脚本，用 uv 装隔离环境，不污染系统 Python）： bash curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash 装完开个新终端（或 source ~/.zshrc）。
  2. 初始化：octop init——交互向导会建 SQLite 库、JWT 密钥和第一个管理员账号（密码至少 8 位、字母+数字）。
  3. 启动：octop run——前台启动 API + Web 控制台。想常驻就 octop service start 注册成系统服务。
  4. 打开浏览器访问 http://127.0.0.1:8088，在控制台里配模型 provider（OpenAI 兼容/DashScope/Ollama 等）然后开聊；想接飞书/微信/Telegram，用 octop channel 按提示绑。

预期效果：本机跑起一个带 Web 面板的多 agent 助手，所有对话、记忆、凭证都在 ~/.octop/，之后还能接 IM 渠道、配定时任务、当家庭 AI 中枢用。完整文档见 GitHub README。
