🤖 今日 AI Coding 动态

四家大厂同认一个训练退出信号：以后 robots.txt 写一行就够了

跟你有啥关系：你要是运营博客、文档站、开源项目主页，以前想谢绝训练，得给每家爬虫各写一套规则，新爬虫一来又得补——这回四家终于肯读同一个信号了。OpenAI、Google、Microsoft、Anthropic 10 月 30 日宣布支持 IETF AI Preferences 工作组草案里的共享训练偏好信号：网站主在 robots.txt 里写 User-Agent: __usage_ai-training 加 Disallow: /，就能一次性向参与的厂商表达"不用于训练"，还可以用 Allow: 抠出例外。时间表并不整齐：Anthropic 称已开始落地，OpenAI 说"未来几个月内"，Microsoft 定在 2027 年 2 月 1 日，Google 定在 2027 年初；各家原有的爬虫控制（如 GPTBot、Google-Extended）继续有效，不会被新信号取代。我的判断：先别急着删旧规则——这份文件目前还只是个人 Internet-Draft，不是正式标准，而且它只管"以后不再拿去训练"，不负责把已进训练集的内容吐出来；正确姿势是新信号先加上、旧规则先留着，等各家落地时间表兑现再收尾。原文链接

Anthropic 给 Ultra 松绑：5 小时限制没了，周限额还在

跟你有啥关系：重度用 Claude Code 的人最懂那种痛——一个长会话跑到一半被 5 小时窗口切断，上下文和劲头一起断掉。Anthropic 10 月 30 日调整了 Claude Max 档位：Max 5x 改名 Max（每月 100 美元）、Max 20x 改名 Ultra（每月 200 美元），价格不变；已验证的 Ultra 账号即日起取消 5 小时限制，多数现有订阅者直接生效，新账号验证通过后解除；周限额维持不变。我的判断：这对 Ultra 用户是实打实的体验修复——长会话不用再被窗口切碎，但别把它读成"无限量"：周上限仍在，重活还是得分批排，别在周初就把一周的量一把烧光。原文链接

Cursor 市场被篡改的 Claude Code 扩展：装过的人先自查

跟你有啥关系：扩展市场是 coding agent 的信任根基——你装的不是官方扩展，而是别人冒名改过的版本，它就能顺手摸走主机信息、给攻击者留后门。路透社 10 月 30 日报道，Cursor 称一个被恶意修改的 Claude Code 扩展 10 月 29 日出现在其 VS Code 扩展市场上，从约凌晨 2:27（太平洋时间）挂到下午 1:35，波及至多 5000 名用户；该扩展并非 Anthropic 开发，它试图收集主机名、用户名、操作系统与公网 IP，还试图为攻击者建立远程访问——Cursor 称关键一步在多数机器上会因需要管理员权限而失败。事发后 Cursor 下架了该版本、封禁其分发、为防万一短暂关闭整个市场，重建后已恢复上线，并称其他扩展不受影响。我的判断：立刻做两件事——检查自己有没有在 10 月 29 日那段时间装过或更新过这个扩展，有就按 Cursor 的指引清理并换掉相关凭证；以后装 agent 类扩展先认准发布者，别只看名字和下载量。原文链接

Android Studio Rabbit 2 转正：40 多个 coding agent 都能接进官方 IDE

跟你有啥关系：Android 开发者以前只能在内置助手和自己惯用的 agent 之间二选一，现在官方 IDE 说"都行，你带自己的 agent 来"。Google 10 月 28 日宣布 Android Studio Rabbit 2 进入稳定版，核心是 Bring Your Own Agent：可接入 40 多个外部 coding agent，包括 Claude Agent、OpenAI Codex、Junie 与 Google Antigravity；接进来的 agent 能用 Android Studio 的工具——跑构建、启动模拟器、读 Logcat，还能用 Android skills 做复杂任务；内置 agent 仍然免费提供。我的判断：这对 Android 团队最实际的意义是"不用为了换 agent 而换 IDE"——先在非主线分支上接一个你已经在用的 agent，跑通构建+模拟器+日志这条链路再推广，别一上来就全员切过去。原文链接

是什么：Strava 10 月 28 日宣布，美国订阅用户可以把 Strava 账号连进 Google Gemini，直接问自己的训练历史——比如同心率下是不是越跑越快、力量训练对跑步有没有影响、上一场比赛每英里怎么跑的。解决什么问题：训练数据躺在 App 里翻起来费劲，现在用一句话就能问出趋势、最佳成绩对比与 streak，还能结合每次活动记录的气温、湿度与风速估算天气拖慢了多少。免费额度/价格：连接本身不另收费，但需要 Strava 订阅，适用于所有 Gemini 档位（截至撰写时）。适合谁：美国的 Strava 订阅跑者；注意连接是只读的、随时可断，Gemini 改不了你的活动记录，美国以外暂无上线时间。原文链接

⭐ 今日 GitHub 热门项目

lfnovo/open-notebook：自己搭的 NotebookLM，模型随便换

🎓 3 分钟小教程：给你的网站加一行训练退出信号

前置条件：你有一个能改 robots.txt 的网站（博客、文档站都行），以及一分钟时间。

  1. 打开网站根目录的 robots.txt，在文件里加两行（先加在文件末尾，别动已有的规则）： User-Agent: __usage_ai-training Disallow: /
  2. 想留例外时，在下面补 Allow: 行，例如只放行某个目录——写完保存，确认文件能在 你的域名/robots.txt 直接打开。
  3. 别删旧规则：各家原有的爬虫控制（如 GPTBot、Google-Extended）继续有效，新信号落地时间各家不同（Anthropic 已开始、OpenAI 未来几个月、Microsoft 2027 年 2 月 1 日、Google 2027 年初），旧规则是过渡期的保险。
  4. 设个日历提醒：2027 年初回来看一眼各家是否已兑现，再决定要不要精简旧规则；同时记住，这个信号只管"以后不拿去训练"，不负责清理已经进训练集的内容。

预期效果：一行配置，同时向 OpenAI、Google、Microsoft、Anthropic 四家表达训练退出意愿——比给每家各写一套规则省事得多；但别把它当成法律武器，它目前还只是草案信号，真正的约束力来自各家的兑现与后续标准。
