🤖 今日 AI Coding 动态

Anthropic 发 Claude Haiku 5.5：小模型价格战开打，Max/Team 送月度 API 额度

10 月 7 日，Claude 5.5 家族第三款落地。定位高频低成本任务与大模型的"subagent"：10 万 token 内 $0.10/M 输入、$0.50/M 输出，官方称平均比 Haiku 4.5 便宜约 75%，直接对标 GPT-6 Luna。基准：Terminal-Bench 4.0 39.2%（前代为 0）、FrontierCode 1.1 46.4%；1M 上下文，Haiku 首个可调 effort 档。model ID claude-haiku-5-5，已在 Claude Platform / AWS / GCP / Azure 上线。同日还加了料：Sonnet 5.5 缓存读价格腰斩到 $0.10/M；Max 5x 送 $100/月、Max 20x 送 $200/月 API 额度，Team 最高 $500 共享池；SDK 新增 computer-use 与 browser-use beta 工具。Reuters / 定价与额度细节（链接截至撰写时可访问）

我的看法：Haiku 一直是"便宜干脏活"的定位，这次配上可调 effort 和还不错的 agent 基准，明显冲着 subagent 场景去的。小模型价格战对开发者是实打实的好事——日常任务、CI 里跑的小活成本直接砍一刀。国内直连用不了，等中转渠道跟进降价。

OpenAI GPT-6 全量登陆 ChatGPT："Intelligent UI"让回答自带交互界面，免费档今日推送

10 月 7 日起，GPT-6 在 ChatGPT 的 Chat tab 全量推送，新能力 "Intelligent UI"让回答可内嵌可交互的图表、表单、按钮、计算器和小工具（比如账单分摊器）。10-07 先上付费档（Plus/Pro/Business/Enterprise，GPT-6 Sol 驱动），Free 和 Go 档从今天 10-08 开始推送（GPT-6 Luna 驱动）。顺带：产品负责人在 X 公布 Codex + ChatGPT Work 合计 4000 万活跃用户，付费账号将获得"banked usage reset"额度储备。unite.ai / runtimewire（链接截至撰写时可访问）

我的看法：聊天界面正在往"可操作界面"进化——以后回答不只是文本，"点两下就把事办了"会成为默认体验。对做 ChatGPT 插件和小工具的人是个信号：官方亲自下场做交互组件了，第三方得往更深的地方做。

Google DeepMind 开源 EmbeddingGemma 2：740M 多模态 embedding，端侧也能跑

10 月 6 日发布，基于 Gemma 4、Apache 2.0 开源。文本、代码、图像、音频、视频统一映射到同一 768 维向量空间（可截断到 512/256/128，存储降到 1/6）；8K 上下文（v1 的 4 倍）；MTEB Code 78.68（v1 68.76）；模块化按需加载（文本 270M / 视觉 170M / 音频 300M）；Pixel 11 Pro 上量化后文本模型 191MB、全模态 567MB；权重已上 Hugging Face 和 Kaggle，ML Kit（Android）数周后支持。marktechpost（链接截至撰写时可访问）

我的看法：embedding 模型的端侧化挺有意义——检索增强不用每次都调云端 API。做 RAG 的可以关注下，代码检索涨了快 10 个点，值得一试。

Stack Overflow 2026 调查：Claude Code（65.5%）首次超过 GitHub Copilot（58.7%）

30,903 有效回复、169 国。AI coding agents 过去一年使用率：Claude Code 第一，GitHub Copilot 第二，OpenAI Codex 29.5%，Cursor 25.5%。IDE 侧：VS Code 70.9% 遥遥领先，Cursor 第六 14.9%、Zed 11.4%、Windsurf 3.2%。73% 受访者每天用 AI 编程助手，但只有 9.6% 会直接采用 AI 答案不加验证。visualstudiomagazine（链接截至撰写时可访问）

我的看法：agent-first 的工作流彻底赢了，Copilot 这种补全形态被 agent 形态超车，是今年最大的格局变化。Cursor IDE 市占 14.9% 也很有意思——agent 火，但人还是待在 VS Code 里。

顺带一个官方认账的插曲：GitHub 承认多款 IDE 把 agent 会话迁到 Copilot SDK 后未标识来源 IDE，导致使用指标里 agent 活跃度被系统性低估（历史缺失数据无法回填，计费不受影响），VS Code 1.139.0+ 已修复——看团队 AI 采用率报表的注意口径。changelog

⭐ 今日 GitHub 热门项目

addyosmani/agent-skills

生产级 agent skills 全家桶：25 个 skill 覆盖开发全生命周期（spec → plan → build → test → review → ship），npx skills add 一条命令装进 70+ agent。解决什么问题：agent 会写代码但不懂工程纪律——需求先对齐、测试先写、合并前过质量门，全靠 skill 强制执行。⭐ 约 102,785（截至撰写时）。适合：用 Claude Code/Cursor/Codex 做正经项目、被 agent 屎山坑过的人。注：和昨天推的 mattpocock/skills 同赛道、不同作者（Addy Osmani）。项目地址

manaflow-ai/cmux

为 AI coding agent 而生的开源 macOS 终端（基于 Ghostty）：竖排标签 + 通知系统，哪个 agent 在等你输入一眼看到。解决什么问题：同时开十几个 Claude Code/Codex 会话，标签栏挤爆、通知全是"Claude is waiting for your input"没上下文——cmux 给每个 pane 蓝圈提醒，侧栏显示 git 分支/PR 状态/监听端口，还带可编程浏览器和 SSH。⭐ 约 27,827（截至撰写时）。适合：Mac 上并行跑多个 agent 会话的重度用户。项目地址

trycua/cua

computer-use 2.0 开源套件：跨 OS 桌面操作驱动（Cua Driver）、本地 VM（Lume）、给 agent 的完整桌面（Cua Spaces）+ 评测基准（Cua Bench），MIT 协议。解决什么问题：想让 agent 像人一样操作桌面应用（点按钮、填表单），需要驱动层、沙箱和评估工具——cua 一把给齐。⭐ 约 28,729（截至撰写时）。适合：想做桌面自动化 agent、评测 computer-use 模型的人。项目地址

cloudflare/security-audit-skill

Cloudflare 官方出品的安全审计 skill：六阶段流程（侦察 → 覆盖式猎杀 → 候选独立验证 → 结构化输出 → 独立复核 → 报告），结论分 confirmed / needs_validation / rejected 三档，带 JSON schema 机读校验。解决什么问题：让 agent 做安全审计时满嘴跑火车——这个 skill 用"发现者 ≠ 验证者"的对抗式流程，只认有完整证据链的 confirmed。⭐ 约 26,025（截至撰写时）。适合：想给自己仓库做一次 agent 安全审计的人（今天的教程就用它）。项目地址

🛠️ 值得一试的工具：raddebugger

是什么：Epic Games 官方开源的原生图形调试器（MIT），用户态、多进程；顺带自研了 RAD Linker——巨型可执行文件链接快约 50%（官方测试数据）。

解决什么痛点：Windows 原生调试工具选择少，大型 C++ 项目（游戏引擎这类）链接慢、调试体验差。

免费额度：完全免费开源，有预编译 release 二进制。

verdict：观望 —— 还在 alpha，目前仅支持本机 Windows x64 + PDB（Linux/DWARF 在路线图上）；C++ 游戏/引擎开发者可以尝鲜，不建议现在当主力调试器。⭐ 约 7,851（截至撰写时）。项目地址

🎓 3 分钟小教程：用 Cloudflare 的 security-audit skill，让 agent 给你的仓库做一次带证据链的安全审计

Trending 上 Cloudflare 官方那个安全审计 skill，我觉得比大多数"帮我找漏洞"的 prompt 强在：它强制对抗验证，只认有证据链的结论。下面是 3 分钟跑起来。

前置条件：一个支持并行 sub-agent 的 coding agent（Claude Code 等）、装好 Node.js（跑零依赖的校验脚本）、一个你想审计的仓库

  1. 装 skill（一条命令）： npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit 用户级安装加 --global。
  2. 把 agent 启动在（或指向）要审计的仓库目录。默认审计产物写到 ~/security-audit-skill/<仓库名>/run-<N>，只在你明确指定版本控制忽略的目录时才写进目标仓库。
  3. 在 agent 里说：security audit this codebase（或 find security vulnerabilities in ./src），skill 自动激活，走完六阶段：侦察建架构图谱 → 覆盖式猎杀 → 换一批 fresh agent 独立验证每个候选 → 写 findings.json 并过 schema 校验 → 独立复核 → 输出 REPORT.md / FINDINGS-DETAIL.md / NEEDS-VALIDATION.md。
  4. 只看 confirmed 档结论——有完整源码证据链和可观察的影响；needs_validation 是有未解事实的存疑项，别当漏洞报。

预期效果：得到一份带证据链、可机读、可复跑（多次跑覆盖率叠加）的安全审计报告。

注意：让审计 agent 实际执行目标代码需要 OS 级沙箱（禁外网、环境白名单、资源限制、只写指定目录）；没这个条件时流程会自动降级为静态推导，结论停在 needs_validation。审计/逆向仅用于自己或已授权的代码。项目地址
