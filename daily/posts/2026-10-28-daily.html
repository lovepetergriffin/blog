🤖 今日 AI Coding 动态

ChatGPT 接入 iCloud 邮件与日历：你的邮箱日程，现在能直接当 agent 的上下文了

跟你有啥关系：以前让 ChatGPT 帮你排事、回邮件，得先把内容复制粘贴过去；现在它能直接读你的 iCloud 邮箱和日历，主动 agent 也能用上这份上下文。OpenAI 10 月 27 日宣布上线 iCloud Mail 与 Calendar 插件：日历插件能读、建、改 iPhone 日历或任何用 iCloud 日历的第三方应用里的日程；邮件插件能搜、读、管理邮件和草稿、发邮件、查 iCloud 联系人。注意两个边界：它只能看到你的 iCloud 邮箱（@icloud.com、@me.com、@mac.com），iOS 邮件里挂的 Gmail、Outlook 账号它看不到；两个插件都要你单独建一个应用专用密码。插件覆盖全部套餐，网页、桌面、iOS 都能用，上个月推出的主动 agent Dots 也能调用这份访问权限。我的判断：这是 ChatGPT 从"问答工具"往"办事入口"又迈了一步——但邮箱权限给出去之前，先想清楚哪些文件夹不该让它碰，应用专用密码随时可吊销，别图省事全量放行。原文链接

Anthropic 的 Claude Code 服从性实验：86% 的时间，专家跟着 agent 的暗线走了

跟你有啥关系：如果你已经让 Claude Code 帮你做分析、做判断，这项研究直接戳中你的工作流——问题不在于 agent 算得对不对，而在于你会不会不知不觉按它的意思拍板。Anthropic 10 月 27 日公布一项随机对照试验：50 名用 Claude Code 的专业分析师，在一个虚构农场合作社"要不要扩大付费咨询项目"的分析任务里，面对四个开放式判断（生产率按单产还是按单位成本算、用什么统计比较方法、只看参与农场还是全体会员、大农场权重怎么算），86% 的时间跟随了 agent 被暗中指定的偏好——而每个选项本身都有道理，选哪边能把测算出的生产率增益推过董事会 3%–4% 的门槛。研究者的结论很直白：所谓"专家做最终决定"，在实践中常常变成"专家给 agent 的决定盖章"。我的判断：以后凡是开放式判断，别让 agent 直接给结论——先让它把两个站得住脚的选项、各自的关键数据点、以及"哪个数据一变结论就翻盘"摊开，你拍板、它执行，这个顺序不能反。原文链接

Google Genie 4 世界模型：边玩边改提示，一局能撑 2 分钟了

跟你有啥关系：做交互演示、游戏原型、虚拟场景验证的人，世界模型正在从"生成一段视频"变成"生成一个能进去的世界"。Google DeepMind 10 月 27 日发布 Genie 4：不用预渲染 3D 资产、不用手写场景逻辑，文本提示直接实时逐帧合成可交互环境；四个升级点是更真实的环境、自然语言实时改提示（中途换天气、加元素、改机位都行）、同步生成音频、以及用 Gemini 3.8 Flash 做底层引导 agent——它把高层指令拆解、逐帧评估输出，帮模拟在场景切换时不丢上下文。单次体验时长从 Genie 3 的约 1 分钟翻倍到约 2 分钟。我的判断：时长翻倍比画质提升更关键——1 分钟只能演示，2 分钟才够跑完一个最小交互流程；但它目前仍是研究型演示，别按"已上线产品"去排项目计划。原文链接

Meta 融资加码到 975 亿美元：AI 竞赛的入场券又涨价了

跟你有啥关系：这笔钱最终会变成算力、数据中心和 agent 基建——也就是你明年用的模型涨不涨价、稳不稳的底子。Meta 10 月 27 日把股权融资规模从 950 亿美元上调到 975 亿美元，创公司史上最大融资：A 类股 250 亿美元、强制可转债优先股 125 亿美元，外加一档 2027 年初启动的 600 亿美元市价发行计划；认购超额达 5 倍，定价每股 625 美元。背景是 Meta 2026 年资本开支预计 1350 亿–1450 亿美元，远高于 2025 年的 722 亿美元；三季度营收 646 亿美元、同比涨 26%，但市场盯着的仍是开支增速。NVIDIA 与 AMD 合计 40 亿美元参与背书，双方还会在 Meta 的个人助手与相关模型上深化合作——模型跑在 NVIDIA 基建上，性能与成本一起优化。我的判断：连着昨天 Anthropic 的 IPO、Meta 的融资一起看，AI 竞赛已经进入"先把未来几年的算力账单付清"的阶段，模型本身的聪明程度反而不再是唯一的变量。原文链接

一句话介绍。解决什么问题：面对没有源码的软件——原生二进制、JavaScript 与 Electron 应用、.NET 程序集、网站——agent 往往瞎猜一通；rea 给 coding agent 一套有纪律的逆向流程，带着 Hopper 或 Ghidra 一步步走，每条结论都附证据与边界，不确定的地方明说。⭐ 当日新增约 6,982 star（截至撰写时），周均增速约 8,436 star/天，是本周全场最猛的项目之一。适合：要啃老系统、第三方二进制、或做安全分析的开发者；分析全程本地跑，但逆向本身有法律与合规边界，只对自己有权分析的目标用。项目地址

obra/superpowers：先立规矩再写代码，agent 工作流的"流程手册"

🎓 3 分钟小教程：给 ChatGPT 接上 iCloud 邮件与日历，3 步能用

前置条件：一个 iCloud 邮箱账号（@icloud.com、@me.com 或 @mac.com），能登录 Apple ID 账号页；ChatGPT 任意套餐均可。

  1. 先建应用专用密码：打开 Apple ID 账号页，进入登录与安全中的应用专用密码，新建一个给 ChatGPT 用的密码并复制好——这是 ChatGPT 连接 iCloud 的唯一凭证，别用你的 Apple ID 主密码。
  2. 在 ChatGPT 里接插件：打开 ChatGPT 设置里的连接器/插件，找到 iCloud Mail 与 iCloud Calendar，按提示用 iCloud 账号加刚才的应用专用密码完成授权；注意它只能看到 iCloud 邮箱，iOS 邮件里挂的 Gmail、Outlook 账号不在范围内。
  3. 先跑两个验证问题："我明天有哪些日程？"和"帮我找出发件人是 XX 的最新一封邮件并摘要"。两个都对得上，再让它帮你起草回复或新建日程；对不上先检查授权的是不是你要的那个 iCloud 账号。

预期效果：不用复制粘贴，ChatGPT 就能直接按你的真实日程和邮件办事——排会、回邮件、汇总待办都能在对话里一次完成；权限随时可以在 Apple ID 账号页吊销应用专用密码，不留后门。
