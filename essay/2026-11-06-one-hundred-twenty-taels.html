一百二十两银子，怎么分才算公道

发布于 2026-11-06寓言

我们村有三个手艺人：木匠老周、铁匠老郑、陶匠老何。每年秋天，他们合租一辆大车，把各自的货拉到府城的集市上去卖。今年三人同去，回来一算账，净赚一百二十两银子。

分钱的时候，吵起来了。

老周先开口：“平分，一人四十两，最省事。”

老郑摇头：“省事可不公道。账本都在我这儿，前些年咱们人没凑齐，都是两两搭伙去的——我和老周去，赚了九十两；老周和老何去，赚了八十两；我和老何去，只赚了七十两。老周在的搭档都赚钱多，凭什么他和我们拿一样？”

老何也开了口：“那按单干的本事分。我一个人去过一趟，租车、请镖、交摊位费，折腾下来刚好白忙，一文没赚。你们俩呢？”

老周和老郑对视一眼，都不说话——他俩单独去过，也都是白忙，一文没赚。

我在一旁管账本，听着听着，觉得这事儿比看着简单。单干都赚零，按单干的本事分，分母都是零，分不下去。平分吧，老周确实在两档最赚钱的搭档里都占着位置，凭什么和他搭档的另外两个人拿得一样多？

我翻着账本，试着换了种算法：把每个人参加过的两两搭档的赚头加起来。老周是九十加八十，一百七十；老郑是九十加七十，一百六十；老何是八十加七十，一百五十。三个人加起来是四百八，按这个比例分一百二十两：老周四十二两五钱，老郑四十两，老何三十七两五钱。

我把这个数一报，三个人都不吭声了。可我自己先觉得不对劲：九十两那一档，是老周和老郑两个人一起赚的，我把它既算进老周的功劳，又算进老郑的功劳，一笔钱数了两遍。这算法看着公平，其实是把别人的功劳也记到了自己头上。

那天晚上我对着账本想了很久，忽然想到一个笨办法：假装三个人是按某个顺序，一个一个走进集市的。

第一个人先进来的时候，摊子还是空的，他只能拿自己单干的那份——零。第二个人进来，摊子从一个人变成两个人，赚头跟着涨，他拿走涨出来的那部分。第三个人进来，摊子从两个人变成三个人，他拿走最后涨出来的那部分。

三个人有六种进场顺序。我把六种都算了一遍。

就拿老周来说：

  • 周、郑、何这个顺序：老周先进，拿 0；老郑进来，摊子从 0 变成 90，老郑拿 90；老何最后进来，摊子从 90 变成 120，老何拿 30。
  • 周、何、郑：老周 0，老何 80，老郑 40。
  • 郑、周、何：老郑 0，老周 90，老何 30。
  • 何、周、郑：老何 0，老周 80，老郑 40。
  • 郑、何、周：老郑 0，老何 70，老周 50。
  • 何、郑、周：老何 0，老郑 70，老周 50。

六种顺序里，老周拿到的分别是 0、0、90、80、50、50，加起来是二百七十，平均四十五两。

再算老郑。六种顺序里他拿到的分别是 90、40、0、40、0、70，加起来二百四十，平均四十两。

老何呢？六种顺序里他拿到的分别是 30、80、30、0、70、0，加起来二百一十，平均三十五两。

四十五加四十加三十五，正好一百二十两，一文不多，一文不少。

我把这个分法念给三个人听。老周得了四十五两，比平分多五两；老何三十五两，比平分少五两；老郑四十两，不多不少。老何张了张嘴，想说什么，又闭上了——六种顺序里，他有两回确实是最后进场、只拿了零，有一回却拿了八十两的大头，平均下来三十五两，实在没什么可挑的。

那天夜里我又想了一层：这个分法妙就妙在，谁也没法靠嗓门大、靠资格老多拿一文。你的那份，就是你在所有可能的进场顺序里、平均下来给大伙儿多赚的那部分。顺序是假想的，平均是实在的。

故事讲完，概念说清楚

这个故事讲的，是合作博弈论里最著名的分配方法：夏普利值（Shapley value）。它由美国数学家劳埃德·夏普利（Lloyd Shapley）在 1951 年提出、1953 年正式发表，专门回答一个问题：一群人合作赚了一笔钱，每个人该分多少才算公道？

它的算法就是故事里的那个笨办法。把所有合作者排成一队，依次“进门”，每个人进门时拿走的，是“因为你的加入，联盟的总收益多出来的那一部分”，也就是你的边际贡献。所有可能的排队顺序都算一遍，取平均，就是你的夏普利值。写成公式是：φᵢ(v) = 1/n! · Σ[v(Pᵢ ∪ {i}) − v(Pᵢ)]，其中 n 是人数，求和跑遍全部 n! 种排列，Pᵢ 是在排列中排在 i 前面的人组成的联盟。

把故事里的数字重算一遍，机制就站住了。设老周、老郑、老何分别为 A、B、C，各联盟的收益是：单人都是 0，AB 是 90，AC 是 80，BC 是 70，三人全上是 120。A 的边际贡献在六种排列里依次是 0、0、90、80、50、50，平均 (0+0+90+80+50+50)/6 = 270/6 = 45；B 的是 90、40、0、40、0、70，平均 240/6 = 40；C 的是 30、80、30、0、70、0，平均 210/6 = 35。三者相加 45+40+35 = 120，恰好等于三人合作的总收益——这不是巧合，而是这个方法的第一条性质。

夏普利在提出这个值的时候，同时证明了一件事：只要你要求分法满足下面四条很自然的要求，满足这些要求的分法就只有一个，就是夏普利值。

第一，效率：所有人分到的总和，正好等于大联盟创造的价值，不多不少。故事里 45+40+35 = 120，分文不差。

第二，对称：两个人在所有联盟里作用都一样、可以互相替换，分到的就一样。故事里三个人作用各不相同，所以分到的 45、40、35 各不相同；反过来，如果某两个人完全对称，分法绝不会厚此薄彼。

第三，哑元：一个人如果加入任何联盟都不增加任何价值，就什么也分不到。故事里三个人单干都是 0，但这不等于他们是哑元——哑元的意思是“加进任何组合都不添一文”，而老周加进老郑的摊子，收益就从 0 涨到 90，所以他绝不是哑元。

第四，可加性：如果两桩合作同时进行，一个人在合起来的合作里分到的，等于他在两桩合作里分到的之和。这条最技术性，也最有争议，但它保证了分法在“合作可以拆开算”时不会自相矛盾。

这个七十多年前为分钱发明的方法，今天的用处远比集市大得多。机场跑道的修建费怎么摊？1973 年利特尔柴尔德和欧文就用夏普利值算过：飞机越重、对跑道的要求越高，就该多摊——按“所有飞机按重量排序依次进场”的平均边际成本来摊，轻型飞机的拥有者不用为重型飞机才需要的加厚跑道买单。机器学习里的 SHAP 解释方法也是同一个思路：把一次模型预测看成一群特征合作赚来的“收益”，每个特征的贡献就是它在所有特征组合里的平均边际贡献，模型为什么给出这个预测，就此有了可以逐项对账的解释。

所以下次再遇到“功劳怎么算”的争吵，不妨先别比嗓门。把每种组合的收益写进账本，把所有可能的进场顺序都算一遍，取个平均——公道有时候不是谈出来的，是算出来的。
