货郎老陈的三百个晚上

发布于 2026-11-23寓言

我年轻时在镇上当账房，认得一个货郎，姓陈，叫老陈。老陈挑着一副担子，在上村和下村之间走，针头线脑、盐巴火柴，两个村子都指着他送货。两个村子隔着一道山梁，走过去要一个时辰，他每天只能住一个村子。

老陈有个怪规矩，我问过他好几次，他每次都笑着说同一句话："我只看今晚住哪儿。"

他的规矩是这样的：每晚住下之后，他从布袋里摸一支竹签，摸到什么，明天就去哪儿。住在上村，袋里四支签，三支刻着"留"，一支刻着"走"；住在下村，袋里两支签，一支"留"，一支"走"。摸完把签放回去，第二天晚上再摸一次。

我一开始没觉得这有什么。直到有一年冬天，两个村子的客栈掌柜打了个赌。

那年老陈第一晚住在下村。下村的掌柜拍着桌子说："他从我这儿起步，今年肯定住我这儿多！"上村的掌柜不服："各凭本事，走着瞧。"

赌注是一坛好酒。我闲着也是闲着，就在账本上替他们记下了：老陈每晚住哪儿。

记了几天，我看出点门道，拿笔在手心算了起来。

老陈第一晚在下村，第二晚他住哪儿？下村袋里两支签，一"留"一"走"，一半一半：住上村的可能是一半，住下村的可能也是一半。

第三晚呢？分两种情形算：

  • 第二晚住上村（可能一半），第三晚还住上村的可能就是四分之三；
  • 第二晚住下村（可能一半），第三晚去上村的可能是一半。

加起来，第三晚住上村的可能 = 1/2×3/4 + 1/2×1/2 = 3/8 + 1/4 = 5/8。

第四晚，我照样算：5/8×3/4 + 3/8×1/2 = 15/32 + 3/16 = 21/32。

第五晚：21/32×3/4 + 11/32×1/2 = 63/128 + 11/64 = 85/128。

第六晚：85/128×3/4 + 43/128×1/2 = 255/512 + 43/256 = 341/512。

我把这串数写在账本边上：1/2、5/8、21/32、85/128、341/512……

1/2 是 0.5，5/8 是 0.625，21/32 是 0.65625，85/128 是 0.6640625，341/512 是 0.666015625。

这个数一路往上爬，爬得越来越慢，像是朝着什么地方去，又永远差那么一点点。它要去的地方，我越看越眼熟：三分之二。

我不信邪，换了个算法又算一遍。这回我假设老陈第一晚住在上村——不是下村：

第二晚住上村的可能：3/4。

第三晚：3/4×3/4 + 1/4×1/2 = 9/16 + 1/8 = 11/16。

第四晚：11/16×3/4 + 5/16×1/2 = 33/64 + 5/32 = 43/64。

第五晚：43/64×3/4 + 21/64×1/2 = 129/256 + 21/128 = 171/256。

这串数是 0.75、0.6875、0.671875、0.66796875，一路往下走，同样朝着三分之二去。

我盯着账本看了半晌，忽然明白了。

不管老陈第一晚住在哪个村子——下村也好，上村也好——日子一长，他在上村过夜的可能，都会停在同一个数上：三分之二。另一头，下村就是三分之一。起点是什么，根本不重要。

我又验算了一遍，确认这个数真的"停得住"：假设某天他住在上村的可能是 2/3、住在下村的可能是 1/3，那么第二天住在上村的可能 = 2/3×3/4 + 1/3×1/2 = 1/2 + 1/6 = 2/3，一分不多，一分不少。这是个自己推着自己走、永远不变的数。

三百天记下来，账本上的总数也对上了：平均下来，三百个晚上里，老陈大约二百夜住上村、一百夜住下村——不多不少，正好是三分之二对三分之一。

我把账本推到两个掌柜面前。下村的掌柜愣了半天："他第一晚明明住在我这儿！"

"第一晚住哪儿，"我说，"和第三百晚住哪儿，没关系。老陈每天只看今晚住哪儿——可只要他这么走下去，住哪间客栈，迟早是个定数。"

那坛酒，最后归了上村的掌柜。

故事讲完，概念说清楚

这就是马尔可夫链（Markov Chain），随机过程里最基本、也最有用的模型之一，由俄国数学家安德烈·马尔可夫（Andrey Markov）在 1906 年前后提出。

它的核心只有一句话，叫马尔可夫性，也叫无记忆性：在已知"现在"的条件下，"未来"与"过去"无关。老陈每晚摸签，只看今晚住在哪个村子，不看他昨天、前天、大前天住过哪儿——他走了三百天，可决定明天的，永远只有今天。这正是故事里那句"我只看今晚住哪儿"的数学版本。

描述这样一个过程，只需要两样东西：

第一，状态。老陈只有两个状态：住上村，住下村。

第二，转移概率，也就是从一个状态走到下一个状态的可能有多大，可以排成一张表——数学上叫转移矩阵：

今晚住哪儿 明晚住上村 明晚住下村
上村 3/4 1/4
下村 1/2 1/2

每一行的数加起来都是 1：从任何一个状态出发，明晚总得住在某个村子。

故事里最出人意料的那一点，叫平稳分布。当一根链满足一定条件（两个状态互相都能走到，而且不会被困在固定的循环里），不管从哪个状态出发，日子一长，各状态出现的概率都会收敛到同一个分布上，并且一旦到了这个分布，就永远不再变化——数学上写成 πP = π，也就是"分布乘以转移矩阵，等于它自己"。

把故事里的数代进去验算：平稳分布是上村 2/3、下村 1/3。

  • 第二天住上村的可能 = 2/3×3/4 + 1/3×1/2 = 1/2 + 1/6 = 2/3；
  • 第二天住下村的可能 = 2/3×1/4 + 1/3×1/2 = 1/6 + 1/6 = 1/3。

和出发时一模一样，纹丝不动。这就是为什么两条从不同起点出发的数列——下村出发的 1/2、5/8、21/32、85/128、341/512，和上村出发的 3/4、11/16、43/64、171/256——一个往上爬、一个往下走，最后都停在 2/3 这个地方。起点被时间"洗"掉了，剩下的只有转移规则本身决定的定数。

还有一个更强的结论，叫遍历定理：在这样的链里，长期下来各状态出现的频率也会收敛到平稳分布。所以三百天里老陈平均约二百夜住上村、一百夜住下村，不是巧合，是定理保证的——注意这是平均意义上的数，某一年实际数下来可能是 198 夜、也可能是 205 夜，但天数越长，频率离 2/3 就越近。

这套东西的用处远不止算货郎住哪儿。搜索引擎给网页排序的 PageRank，本质就是一张巨大无比的转移矩阵上的平稳分布；天气预报里"今天晴、明天雨的可能"，语言模型里"上一个词是'我'、下一个词最可能是'们'"，背后都是同一条链。只要一个过程"下一步只看现在"，马尔可夫链就能把它装进来，算出它长期的归宿。

所以老陈那句话其实是个很深的道理：只看今天，并不等于没有明天。恰恰相反——当每一步都只取决于现在，漫长的未来反而会被今天的规则锁死，收敛到一个谁也改不了的定数上。
