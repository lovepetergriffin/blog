Trae 保姆级教程：字节跳动的免费 AI 编程神器，从安装到做出第一个项目

发布于 2026-10-25新手TraeAI 编程教程免费工具

一句话先说结论：还没掏钱、想先免费把 AI 编程用起来，先装 Trae。 它是字节跳动的 AI 原生 IDE，国内网络直连、中文理解深，免费就能从一句话做出一个能跑、能点的 Demo；等你摸清自己到底需不需要付费工具，再决定要不要买 Cursor 或别的。

跟你有啥关系：Cursor、Windsurf 的 Pro 都是 $20/月起，免费版处处限量。Trae 的卖点就是把"免费"做到底——对学生、刚入门、还没确定主力工具的人来说，零成本先跑通一次完整流程，比看十篇对比文都有用。

先说 2026 年 10 月的一个重要变化

Trae 在 2026 年 10 月 9 日把原来的 TraeCode（AI IDE）和 TraeWork（Agent 平台）合并成了一个统一产品，就叫 TRAE：一个入口，Agent 模式和 IDE 模式可以切换，桌面、网页、移动三端打通。

这对你读教程意味着两件事：

  1. 旧教程里的名字可能对不上你装到的版本。 以前的 Builder 模式、SOLO 模式，在新版里对应的是 Agent 模式；如果你装到的还是灰度前的旧版，界面标签会不一样——按功能找，别按名字死磕。
  2. 免费额度的口径变了，要特别小心。 合并后的公开信息显示，免费档是一次性额度、用完不按月重置，不是"每月白嫖"。也就是说，免费档更像一个试用装，不是长期主力。这篇教程的实战部分就是按"额度要省着花"来设计的：先想清楚再让 Agent 动手，小修小补走 IDE 模式。

价格与版本截至 2026 年 10 月，厂商改价快，掏钱前去官网再确认一遍。

安装：三步，不用绑卡

  1. 去 Trae 官网下载你系统的版本（Mac、Windows、Linux 都有），安装后注册登录。
  2. 如果你以前用 VS Code，安装时会问你要不要导入 VS Code 的扩展、设置和快捷键——选导入，你原来的手感不用重练。
  3. 进设置看一眼模型选择：国内版优先看豆包、DeepSeek 这类国内能直连的模型；别一上来就选最贵的模型，先用默认档跑通流程。

实战：从一句话到一个能点的待办清单网页

这是本篇的核心：不讲概念，直接做一个东西出来。目标是一个待办清单网页——能添加任务、能打勾完成、能删除，数据存在浏览器本地。

第 1 步：Agent 模式，让它先出 Demo

新建一个空文件夹，在 Agent 模式里只发一句话，越具体越好：

用 HTML、CSS、JavaScript 做一个待办清单网页：可以添加任务、点击打勾完成、可以删除单条，任务存在 localStorage 里刷新不丢，界面干净、手机上也能正常看。

然后看着它干活：它会自己建文件、写代码、跑起来给你一个能点的预览。这一步别急着改细节，先确认 Demo 能跑、三个功能都通。跑不通先看它报的错，把报错原样贴回去让它修，别自己上手改代码——免费额度要花在刀刃上。

第 2 步：IDE 模式，精修你不满意的地方

Demo 跑通后，切到 IDE 模式，像改普通代码一样改：

  • 觉得样式丑？选中 CSS 里对应的部分，让它换一套配色、把按钮改大一点。
  • 想加功能？比如"按已完成/未完成筛选"，在 IDE 里选中相关代码，让它只改这一处，别让它重写整个文件。

这一步的关键是一次只改一处，改完刷新看一眼。Agent 一次改全文件最容易把刚跑通的东西改崩，返工烧的都是你的额度。

第 3 步：检查三件事再收工

  1. 刷新页面，任务还在不在（localStorage 有没有生效）。
  2. 手机浏览器打开看一眼，布局有没有挤成一团。
  3. 把项目文件夹用 Git 初始化、提交一次——以后改崩了能回滚，这一步不花额度但能救命。

做完这三步，你就完整跑通过一次"想法 → Demo → 精修 → 可交付"：这就是 AI 编程的完整手感，之后换任何工具，流程都是一样的。

免费额度怎么省着花

  • 先想、后说。 发给 Agent 的每一句话，先想清楚要什么、不要什么，含糊的指令返工最多。
  • 小改动别开 Agent。 改个文字、换个颜色，自己在 IDE 里改两行，比开一次 Agent 便宜得多。
  • 报错先贴原文。 把报错信息完整贴回去，比你自己描述"好像有个问题"省至少一轮。
  • 别拿额度练手。 想练提示词、试边界情况，先用免费的对话工具练，确定了再进 IDE。

常见坑

  • 界面跟教程对不上： 大概率是你装到的是合并后的新版或还在灰度的旧版，按 Agent 模式 / IDE 模式这两个功能找，别按 Builder、SOLO 这些旧名字找。
  • 免费额度突然没了： 合并后免费档是一次性额度，不是每月重置——用完就得等或升级，别以为下个月会回来。
  • 模型选错： 国内直连优先选豆包、DeepSeek；选了需要特殊网络的模型，报错先查网络和模型可用性，别先怀疑代码。
  • 代码里有隐私信息： 别把公司代码、密钥、真实用户数据直接贴进 Agent 对话，教程里的小项目无所谓，真实项目要先看隐私设置。

我的 verdict

Trae 值得作为你的第一个 AI 编程工具：免费、中文友好、国内直连，一次实战就能摸清 AI 编程到底是怎么回事。它的免费档不是长期主力——额度用完、需求上来了，再按《Cursor vs Windsurf 深度对比》那篇的选型表去挑付费工具，那时你已经知道自己要什么了，不会被营销话术带跑。
