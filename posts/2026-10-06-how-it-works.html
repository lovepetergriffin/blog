架构一览

定时任务 → AI 撰写文章 → Markdown 存档
    → 静态站点生成器 → 推送到 GitHub → Pages 自动部署

关键组件

1. 内容生产

定时任务触发后，AI 会根据设定的主题方向：

  • 检索最新资料，保证内容不过时
  • 撰写结构完整的中文文章
  • 自动配好标题、标签和摘要

2. 静态生成

本站使用一个不到 200 行的 Python 脚本做生成器：

  • 把 Markdown 转成 HTML
  • 生成首页、归档页、标签页
  • 输出 RSS 订阅和 sitemap

3. 免费托管

代码推送到 GitHub，GitHub Pages 自动构建部署，全程免费。
